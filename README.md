# sonix_docs

토이 프로젝트 15개에서 **되풀이해 재발명한 패턴**을 모아 둔 곳.

프로젝트 문서를 여기로 옮겨 오지 않는다. 각 프로젝트의 `README.md`·`CLAUDE.md`·
`docs/` 는 코드와 함께 변하므로 코드 옆에 그대로 둔다. 여기 남기는 것은 **여러
프로젝트에서 독립적으로 같은 답에 도달한 것들** — 그래서 다음 프로젝트를 시작할 때
처음부터 다시 겪지 않아도 되는 것들뿐이다.

## 왜 복사하지 않는가

문서 허브가 죽는 방식은 정해져 있다. 전부 복사해 넣는다 → 원본이 바뀐다 → 사본은
안 바뀐다 → 6개월 뒤 허브를 읽은 사람이 **틀린 버전을 믿는다**. 이 시점부터 허브는
없느니만 못하다. 그래서 여기서는 문서를 프로젝트가 아니라 **수명**으로 가른다.

| 수명 | 예 | 사는 곳 |
|---|---|---|
| 코드와 같이 변함 | `ARCHITECTURE.md`, `API.md`, 프로젝트 `CLAUDE.md`, `plans/` | **각 프로젝트 레포** (여기엔 링크만) |
| 프로젝트를 넘어 재사용 | 검증 게이트, 헤드리스 하네스, rules/skills 패턴 | **여기** |
| 끝난 일회성 | 완료된 plan, brainstorm, `TODO_NEXT.md` | 각 레포 `docs/archive/` |

판별 기준 하나: **그 문서가 특정 레포의 코드를 고쳐야 낡는가?** 그렇다면 그 레포에
있어야 한다.

## 이 저장소의 규칙

- **근거 없는 문장을 쓰지 않는다.** 수치를 적으면 언제 잰 것인지 함께 적는다.
- **낡은 것은 지운다.** 추가만 하면 여기도 무덤이 된다.
- 프로젝트 문서를 인용할 때는 복사하지 말고 **경로로 가리킨다**.
