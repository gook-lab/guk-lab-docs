# 사람이 읽는 문서

이 폴더는 **사람**을 위한 곳이에요. 나머지 폴더(`playbooks/`, `harness/`)는
작업 중인 저와 에이전트를 위한 것이고, 여기는 처음 온 분 — 채용 담당자,
같이 일할 사람, 그리고 반년 뒤의 저 — 를 위한 거예요.

기준이 달라요. 저쪽은 **정확해야** 하고, 여기는 **읽혀야** 해요.

| 문서 | 누가 읽나 |
|---|---|
| [프로젝트 투어](tour.md) | 뭘 만들었는지 훑고 싶은 분. 프로젝트당 3분이면 돼요 |
| [기술 선택 기록](decisions.md) | "왜 그렇게 했어요?"가 궁금한 분 |
| [시작하기](getting-started.md) | 직접 돌려보려는 분. 전제조건과 함정도 적어뒀어요 |

## 읽는 순서

처음이라면 [투어](tour.md)부터 보시는 걸 추천해요. 특정 프로젝트가 눈에 들어오면
그 레포로 가시고, "어떻게 판단했는지"가 궁금하면 [결정 기록](decisions.md)으로
가시면 돼요.

## 여기 없는 것

**기술 사양은 각 레포의 README에 있어요.** 여기로 복사해 오지 않아요 — 사본은
원본이 바뀌어도 안 바뀌어서, 결국 어느 게 맞는지 모르게 되거든요. 여기 있는 건
여러 프로젝트를 가로질러야 보이는 것들뿐이에요.
